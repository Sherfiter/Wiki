# 课程

计算机本科主干课程的自学讲义,全部按「有人味的讲义」标准重写过:真实命令与输出、踩坑经历、观点、练习,不用速查表糊弄。每门课一个目录,一个文件一讲:

- [Linux / KVM / Docker 课程](./linux-kvm-docker/)——Linux 基础、KVM 虚拟化与 Docker 容器(14 讲)
- [数据结构与算法(C 语言)](./dsa/)——复杂度、线性表、树图、查找排序、DP(12 讲)
- [C 指针课程](./c_pointer/)——C 语言指针专题,直通内存模型与 UB(14 讲)
- [计算机组成原理](./computer-organization/)——数据表示、指令、CPU、流水线、存储层次(10 讲)
- [操作系统原理及应用](./operating-system/)——进程、调度、同步、内存、文件(10 讲)
- [数据库原理及应用](./database/)——关系模型、SQL、范式、事务、索引(10 讲)
- [计算机网络](./computer-network/)——分层、TCP/IP、Socket、一次请求全链路(10 讲)
- [编译原理](./compiler/)——词法到代码生成,十章拼一个迷你编译器(10 讲)
- [离散数学](./discrete-math/)——集合逻辑、图论、计数,一路推到 RSA(10 讲)
- [人工智能基础](./ai/)——搜索、博弈、机器学习到大模型(10 讲)
- [软件工程](./software-engineering/)——需求、架构、测试、协作与交付(10 讲)
- [Java 课程](./java/)——Java 语言程序设计(14 讲)
- [Python 课程](./python/)——语法底座、Pythonic 惯用法与实战(10 讲)
- [Web 前端开发入门](./web-frontend/)——HTML/CSS/JS、浏览器、框架、工程化(10 讲)

课程之间的交叉引用(如「计组课第 8 章」)都标了章号,建议搭配食用:计组 + 操作系统、数据库 + 离散数学、Web 前端 + 计算机网络,是三组天然搭档。全部讲义共用一份文风约定(仓库根目录的 STYLE.md),新增课程请先读它。
