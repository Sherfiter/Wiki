# 第 6 章 · 图

图 = 顶点集 + 边集，边可带方向（有向）和权值。它是「多对多」关系，比树更一般，复杂度也更高。

## 6.1 邻接矩阵 vs 邻接表

| 表示 | 结构 | 空间 | 判断边 | 遍历邻居 |
|---|---|---|---|---|
| 邻接矩阵 | V×V 二维数组 | O(V²) | O(1) | O(V) |
| 邻接表 | 每个顶点一个链表 | O(V+E) | O(deg) | O(deg) |

```c
#define MAXV 1000
// 邻接表：V 个顶点的链表头数组，adj[u] 是 u 的出边链表头
typedef struct Edge { int to, w; struct Edge *next; } Edge;
Edge *adj[MAXV];
```

## 6.2 DFS / BFS

DFS 沿一条路走到底再回溯（递归或显式栈），BFS 逐层扩散（队列）。

```c
int visited[MAXV];
void dfs(int u) {
    visited[u] = 1;
    for (Edge *e = adj[u]; e; e = e->next)
        if (!visited[e->to]) dfs(e->to);
}
```

BFS 用队列（第 3 章），首次到达某顶点时的层数就是**无权最短路**。DFS 产生深度优先森林，用于拓扑排序、强连通分量；BFS 用于最短路径、二分图判定。

## 6.3 最小生成树：Prim vs Kruskal

连通带权无向图的生成树中，边权和最小的那棵。

```c
// Prim：从点出发，每次把「离当前树最近」的点并入（贪心 + 优先队列，见第 5 章堆）
// Kruskal：把所有边按权排序，用并查集（第 11 章）判断加入是否成环
```

| | Prim | Kruskal |
|---|---|---|
| 起点 | 顶点 | 边 |
| 依赖 | 优先队列 | 排序 + 并查集 |
| 复杂度 | O(E log V) | O(E log E) |
| 适合 | 稠密图 | 稀疏图 |

## 6.4 最短路径：Dijkstra vs Floyd

**Dijkstra**：单源最短路径，要求边权非负。每次选「当前距离最小」的未确定点，松弛它的邻居，O(E log V)。

```c

```

**Floyd**：多源最短路径，三重循环动态规划（第 10 章），允许负权边（无负环），O(V³)。

```c
// dp[k][i][j]：只经过前 k 个点的 i→j 最短路，压掉 k 维
for (int k = 0; k < V; k++)
    for (int i = 0; i < V; i++)
        for (int j = 0; j < V; j++)
            if (d[i][k] + d[k][j] < d[i][j]) d[i][j] = d[i][k] + d[k][j];
```

> 对比：邻接矩阵 vs 邻接表——矩阵 O(1) 判边、易写，但 O(V²) 空间，稀疏图浪费；邻接表 O(V+E) 空间、遍历邻居快，但判边要扫链表。**稠密图选矩阵，稀疏图选表**。

> 对比：Prim vs Kruskal——两者都是贪心（第 10 章），Prim 长在稠密图（枚举点），Kruskal 长在稀疏图（枚举边）；Kruskal 多依赖并查集判环。

> 对比：Dijkstra vs Floyd——Dijkstra 求单源、需非负权、O(E log V) 更快；Floyd 一次求所有点对、支持负权（无负环）、O(V³) 简单但慢。**问「从 A 到 B」用 Dijkstra，问「所有点之间」用 Floyd**。

> 承上启下：图的遍历复用第 3 章的栈/队列，MST 和最短路的贪心/DP 是第 10 章的方法论落地；「图」作为最一般的关系结构，为第 11 章的并查集、B 树等更专门的结构收尾。
