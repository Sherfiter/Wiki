# 第 4 章 · 串与数组

串（字符串）是特殊的线性表：元素是字符，通常整体操作。数组的存储有大量冗余可压缩——这两件事分别引出 KMP 和矩阵压缩。

## 4.1 串的存储

C 里串以 `'\0'` 结尾的 `char` 数组表示（C 指针第 6 章）。定长数组简单但有上限，堆分配串需手动管理。本课程的串操作一律基于 C 字符串约定：长度用 `strlen`，不含末尾 `'\0'`。

## 4.2 朴素匹配：暴力回溯

```c
// 在 t 中找 p 首次出现，返回下标，找不到返回 -1
int naive(char *t, char *p) {
    int n = strlen(t), m = strlen(p);
    for (int i = 0; i + m <= n; i++) {
        int j = 0;
        while (j < m && t[i + j] == p[j]) j++;
        if (j == m) return i;
    }
    return -1;
}
```

最坏 O(n·m)：如 `t = "aaaaa...b"`、`p = "aaaab"`，每次匹配到最后一个字符才失败，主串指针还要回退。

## 4.3 KMP：利用已匹配信息不回退

朴素失败后 `i` 回退重扫。KMP 观察到失败前已匹配的 `p[0..j-1]` 中，其「最长相等前后缀」可以直接对齐，`i` 不回退。`next[j]` = 子串 `p[0..j-1]` 的最长相等前后缀长度。

```c
void get_next(char *p, int *next) {
    int m = strlen(p);
    next[0] = -1;
    int i = 0, j = -1;
    while (i < m - 1) {
        if (j == -1 || p[i] == p[j]) next[++i] = ++j;
        else j = next[j];
    }
}

int kmp(char *t, char *p) {
    int n = strlen(t), m = strlen(p);
    int *next = malloc(m * sizeof(int));
    if (!next) return -1;
    get_next(p, next);
    int i = 0, j = 0;
    while (i < n && j < m) {
        if (j == -1 || t[i] == p[j]) { i++; j++; }
        else j = next[j];
    }
    free(next);
    return j == m ? i - j : -1;
}
```

KMP 全程 O(n+m)：主串指针不回退，`next` 数组 O(m) 预处理。

## 4.4 特殊矩阵压缩

矩阵元素分布有规律时，不必存满 n² 个，只存「非零/非重复」部分并给出下标映射。

| 矩阵 | 存什么 | 元素个数 | 下标映射（行优先，i≥j） |
|---|---|---|---|
| 对称 | 下三角（或上三角） | n(n+1)/2 | k = i(i+1)/2 + j |
| 三角 | 三角区 + 对角 | n(n+1)/2 | 同上 |
| 稀疏 | 只存三元组 (i,j,v) | 非零元数 t | 顺序表或十字链表 |

对称矩阵 `A[i][j] = A[j][i]`，只存下三角，读 `A[i][j]`（i < j）时转成 `A[j][i]`。稀疏矩阵用三元组表省下大量零元素存储。

```c
// 下三角按行优先存入一维数组，取 A[i][j]（i>=j 为有效元素）
int sym_get(int *b, int i, int j) {
    if (i < j) { int t = i; i = j; j = t; }   // 利用对称性
    return b[i * (i + 1) / 2 + j];
}
```

> 对比：朴素 vs KMP——朴素最坏 O(n·m) 但实现简单、常数小、短串足够；KMP O(n+m) 但需预计算 next、有额外空间。**短串/一次性匹配用朴素，长文本反复匹配用 KMP**。工程上还有常数更优的 BM、Sunday 算法。

> 对比：三种压缩——对称/三角靠「规律」省一半，下标映射 O(1)；稀疏靠「只存非零」省更多，但丢失随机访问，三元组查找要扫 O(t)。前者换时间，后者换空间。

> 承上启下：串是第 3 章线性表的特化，其「匹配」是第 6 章图遍历、第 7 章查找之外的又一类经典算法；KMP 的 next 数组是「空间换时间」的典范，呼应第 1 章的复杂度权衡。
