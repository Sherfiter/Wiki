# Python 课程

Python 的教学痛点是「入门太容易,精通没方向」:三天会写脚本,三年答不出「装饰器到底什么时候用」。这门课按「语法底座 → 惯用法 → 工程能力」的坡度推进:前六章覆盖语言本体,后四章全是「写出 Pythonic 代码」的关键机制(生成器、装饰器、魔法方法)与实战(数据处理、自动化)。每章都强调与 C/Java 的对照——懂另一门语言的人学 Python,最大的收获是「换一种思维方式」。

十章的地图:环境(01)→ 语法(02~04)→ 文件与异常(05)→ 面向对象(06)→ 模块与标准库(07)→ 迭代器与生成器(08)→ 装饰器与魔法方法(09)→ 实战(10):

- [第 1 章 · Python 与环境](./01-Python与环境/)——解释器、REPL、venv、pip
- [第 2 章 · 变量、类型与字符串](./02-变量类型与字符串/)——动态类型、一切皆对象、f-string
- [第 3 章 · 控制流与函数](./03-控制流与函数/)——缩进、推导式、函数参数的全貌
- [第 4 章 · 列表、字典、集合](./04-列表字典集合/)——四大容器与它们的惯用法
- [第 5 章 · 文件与异常](./05-文件与异常/)——with、异常体系、EAFP 哲学
- [第 6 章 · 面向对象](./06-面向对象/)——类、继承、鸭子类型
- [第 7 章 · 模块、包与标准库](./07-模块包与标准库/)——import 机制、 batteries included
- [第 8 章 · 迭代器、生成器与函数式](./08-迭代器生成器与函数式/)——惰性求值、yield、高阶函数
- [第 9 章 · 装饰器与魔法方法](./09-装饰器与魔法方法/)——Python 的「元编程」双雄
- [第 10 章 · 实战:数据处理与脚本](./10-实战-数据处理与脚本/)——CSV、Excel、爬虫、自动化

先修:零基础可入,有 C/Java 基础的人配速更快(对照视角已内置)。教材配合:Python 官方教程(docs.python.org/zh-cn/3/tutorial)、廖雪峰教程(入门)、《流畅的 Python》(进阶圣经)。
