# 第 2 章 · CSS 基础

CSS（层叠样式表）负责「长相」：**选中元素（选择器）→ 声明样式（属性：值）→ 解决冲突（层叠/优先级）**。它作用在 HTML 结构（第 1 章）之上，最终由浏览器计算成每个元素的盒模型再绘制（第 6 章）。

## 2.1 三种引入方式

| 方式 | 写法 | 适用 | 优先级 |
|---|---|---|---|
| 行内样式 | `<p style="color:red">` | 极少数动态样式 | 最高 |
| 内部样式 | `<style>` 写在 head | 单页 demo | 中 |
| 外部样式 | `<link rel="stylesheet" href="a.css">` | 生产环境 | 与出现顺序有关 |

- **外部样式**是工程首选：可缓存、可复用、HTML 与 CSS 分离。
- 三者同时作用于同一元素时，按优先级（下节）而非简单按书写位置覆盖。

```css
/* style.css */
p { color: #333; line-height: 1.6; }
```

## 2.2 选择器

选择器决定「规则套在谁头上」，是 CSS 的入口：

```css
#app { }                 /* ID 选择器：唯一 */
.box { }                 /* 类选择器：可复用 */
p { }                    /* 元素（标签）选择器 */
input[type="text"] { }   /* 属性选择器 */
a:hover { }              /* 伪类：状态（悬停） */
li:first-child { }       /* 结构伪类 */
p::before { }            /* 伪元素：生成内容 */
.nav a { }               /* 后代选择器（空格） */
.ul > li { }             /* 子代选择器（>） */
```

- 后代 `A B` 与子代 `A > B` 的区别：前者匹配**任意深度**的后代，后者只匹配**直接子级**。
- 伪类 `:hover`/`:focus`/`:nth-child(n)` 针对「状态/位置」，伪元素 `::before`/`::after` 针对「不存在的虚拟节点」。

## 2.3 盒模型：一切布局的基本单位

每个元素在页面上都是一个矩形盒子，由四层组成：

```
┌ margin（外边距，透明，向外推开）
│  ┌ border（边框）
│  │  ┌ padding（内边距，内容到边框）
│  │  │  ┌ content（内容，放文字/图片）
```

- `width`/`height` 默认只指 **content** 区。
- **默认 `box-sizing: content-box`** 下，元素实际占宽 = `width + padding + border`，设了 `width: 100px` 再 `padding: 10px` 会变成 120px，极易撑破布局。

```css
.box {
  box-sizing: border-box;   /* width 含 padding 和 border */
  width: 100px;
  padding: 10px;
  border: 2px solid #000;
  /* 内容区实际 = 100 - 10*2 - 2*2 = 76px */
}
```

> 对比：`content-box` vs `border-box`——`content-box` 的 `width` 不含 padding/border，是「内容宽度」；`border-box` 的 `width` 是「盒子总宽度」，内容会被压缩。布局时 `border-box` 更符合直觉（设多宽就是多宽），现代项目通常全局写 `* { box-sizing: border-box }`；`content-box` 是历史默认，精确控制内容宽度时仍用得到。

## 2.4 层叠与继承

- **层叠（cascade）**：同一元素可被多条规则命中，冲突时按「来源 → 优先级 → 书写顺序」裁决。
- **继承（inherit）**：部分属性（如 `color`、`font-*`、`line-height`）会从父元素**自动继承**；盒模型属性（`margin`、`padding`、`border`、`width`）**不继承**。

```css
body { color: #222; }        /* 全站文字颜色被后代继承 */
p { color: inherit; }        /* 显式继承父级 */
.box { width: 50%; }         /* width 不继承，百分比相对父级 */
```

- 用 `inherit` / `initial` / `unset` 可显式控制继承行为。

## 2.5 优先级（specificity）

当多条规则命中同一元素、同一属性时，用**优先级**决定胜负。它是一组权重 `(ID, 类/属性/伪类, 元素/伪元素)`，从左到右比较：

| 选择器 | 权重 (ID, 类, 元素) |
|---|---|
| `p` | (0, 0, 1) |
| `.box` | (0, 1, 0) |
| `#app` | (1, 0, 0) |
| `.nav a:hover` | (0, 2, 1) |
| `#app .box` | (1, 1, 0) |
| 内联 `style` | 1 0 0 0（碾压一切） |

比较规则：**先比 ID 数，再比类数，最后比元素数；同权重比书写顺序，后写的赢**。`!important` 会越过优先级（但不越过来源），是「核弹级」手段，滥用会让代码无法维护。

> 对比：不同选择器的优先级——`.nav a:hover`（0,2,1）胜过 `a`（0,0,1）和 `.box`（0,1,0），但输给 `#app`（1,0,0）。这就是为什么「尽量用类、少用 ID、避免内联」：类的权重适中且可复用，ID 权重过高难以覆盖，内联更甚。

> 承上启下：选择器是从第 1 章的结构里「挑人」，盒模型是第 3 章布局的最小单元，优先级是写大型样式库时避免互相打架的基石。下一章进入**布局**：定位、浮动、flex、grid——它们决定这些盒子**放在哪里、如何伸缩**。
