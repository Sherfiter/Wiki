# Web 前端开发入门

Web 前端开发入门课程讲义，一个文件一讲：HTML → CSS → JavaScript → DOM → 浏览器原理 → 现代工具 → 框架，最后用「前后端协作」把前端和网络、数据库串起来：

- [第 1 章 · HTML 结构与语义](./01-HTML结构与语义/)——元素、语义化标签、表单
- [第 2 章 · CSS 基础](./02-CSS基础/)——选择器、盒模型、层叠与继承
- [第 3 章 · CSS 布局](./03-CSS布局/)——定位 vs 浮动、flex vs grid
- [第 4 章 · JavaScript 基础](./04-JavaScript基础/)——类型、作用域、闭包、this
- [第 5 章 · DOM 与事件](./05-DOM与事件/)——DOM 操作、事件流、事件委托
- [第 6 章 · 浏览器工作原理](./06-浏览器工作原理/)——渲染流程、回流 vs 重绘、与网络的关系
- [第 7 章 · 现代 JavaScript](./07-现代JavaScript/)——ES6+、异步 Promise/async、模块化
- [第 8 章 · 前端框架对比](./08-前端框架对比/)——Vue vs React、虚拟 DOM、响应式
- [第 9 章 · 前端工程化](./09-前端工程化/)——git、npm、打包构建、部署
- [第 10 章 · 前后端协作](./10-前后端协作/)——HTTP/API，网络与数据库
