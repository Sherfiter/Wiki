# Linux / KVM / Docker 课程

这是一门动手课,回答一个实用问题:**怎么在一台机器上跑出多台机器(虚拟化),以及怎么在一台机器上高密度地跑出一堆服务(容器)**。讲义里所有命令我都实际跑过,每章带「常见错误」小节,记录的是真实踩过的坑(装不上先查 BIOS、容器秒退看日志、端口写反方向)。

课程分两半:第 0~6 章是 Linux 与 KVM(虚拟机,隔离硬、开销大),第 7~13 章是 Docker(容器,共享内核、轻快)。两半共享一条主线:操作系统课的机制(进程、namespace、文件系统)在不同抽象层上的应用。和操作系统课的交叉引用已经标好章号,对照读收益最大:

- [第 0 章 · Linux 基础(与 Windows 对比)](./00-Linux基础/)——内核、发行版、桌面、包管理、权限、用户
- [第 1 章 · KVM 概述](./01-KVM概述/)——虚拟化三条路线、KVM 把内核变成 Hypervisor
- [第 2 章 · 安装 KVM](./02-安装KVM/)——三道门检查、全家桶安装、逐层验证
- [第 3 章 · 创建 KVM 虚拟机](./03-创建KVM虚拟机/)——virt-manager 向导、virt-install 参数全解、串口装机
- [第 4 章 · 虚拟机管理](./04-虚拟机管理/)——libvirt 体系、生命周期、克隆、快照
- [第 5 章 · 管理 KVM 虚拟网络](./05-KVM虚拟网络/)——NAT/隔离/桥接、virbr0 零件巡礼
- [第 6 章 · 管理 KVM 虚拟存储](./06-KVM虚拟存储/)——池与卷、qcow2 vs raw、在线扩容四步
- [第 7 章 · 容器技术简介](./07-容器技术简介/)——容器不是轻量 VM、namespace 与 cgroup、unshare 实操
- [第 8 章 · Docker 镜像管理](./08-Docker镜像管理/)——C/S 架构、分层与 overlayfs、镜像命令
- [第 9 章 · Docker 容器管理](./09-Docker容器管理/)——docker run 参数表、生命周期、排错三连
- [第 10 章 · Docker 网络管理](./10-Docker网络管理/)——veth+docker0、三种模式、名字解析
- [第 11 章 · Docker 存储管理](./11-Docker存储管理/)——volume/bind mount/tmpfs、删容器保数据
- [第 12 章 · 使用 Dockerfile 创建镜像](./12-Dockerfile/)——指令详解、缓存顺序手艺、多段构建瘦身
- [第 13 章 · Docker 实战案例](./13-Docker实战案例/)——四条完整流水线、翻车点实录

先修:一台能装东西的 Linux(虚拟机、WSL2、云服务器都行),用户态权限即可。教材配合:Docker 官方文档、鸟哥的 Linux 私房菜(0 章的展开版)、libvirt 文档(4~6 章)。学完这门课的自然下一步:Docker Compose(多容器编排)和 Kubernetes(集群调度),那时的概念会突然变得好懂,因为底层的 veth、cgroup、overlayfs 你都亲手摸过了。
