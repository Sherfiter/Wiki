# Java 课程

这门 Java 课的讲法是「从会写到懂为什么」:语法照教,但每个语法点都配一个真实的坑(字符串 == 的引用陷阱、Integer 缓存 127 的边界、nextInt 后的空行)或一次与底层的对照(JVM 字节码和计组课的 ISA、GC 和 C 的 malloc、synchronized 和操作系统课的 mutex)。Java 啰嗦的地方我会吐槽,它工程化成熟的地方我也会给公道。

十四讲的推进线:先语法基础(1~6),再面向对象主体(7~8),然后是标准库实战(API、集合、GUI、IO、网络、多线程,9~14)。每章末尾都有可动手的练习,大部分只需要一个 JDK 和终端:

- [第 1 章 · Java 概述](./01-Java概述/)——JDK/JRE/JVM 套娃、WORA 的代价与收益、第一波报错
- [第 2 章 · 基本程序设计](./02-基本程序设计/)——八种类型的长度承诺、收窄必须显式、Scanner 的空行坑
- [第 3 章 · 选择结构程序设计](./03-选择结构程序设计/)——短路求值、字符串 == 的世纪之谜、箭头 switch
- [第 4 章 · 循环结构程序设计](./04-循环结构程序设计/)——三种循环怎么选、off-by-one 根治法
- [第 5 章 · 数组](./05-数组/)——数组是对象、Arrays 工具三件套、不规则二维
- [第 6 章 · 方法](./06-方法/)——只有值传递(但对象能被改)、重载、递归
- [第 7 章 · 面向对象(上)](./07-面向对象（上）/)——一个翻车事故讲透封装、构造、this、static、GC
- [第 8 章 · 面向对象(下)](./08-面向对象（下）/)——继承与多态、equals 之谜收线、异常体系
- [第 9 章 · Java API](./09-Java-API/)——String 不可变、包装类缓存、StringBuilder 的性能案、java.time
- [第 10 章 · 集合类](./10-集合类/)——ArrayList vs LinkedList 实测、Map 第一神器、ConcurrentModificationException
- [第 11 章 · 图形用户界面(GUI)](./11-图形用户界面（GUI）/)——事件驱动模型、EDT 纪律(组件认识即可)
- [第 12 章 · 输入输出(IO)](./12-输入输出（IO）/)——try-with-resources、缓冲的意义、乱码案卷宗
- [第 13 章 · 网络编程](./13-网络编程/)——Echo 服务器、TCP 粘包、一线程一连接
- [第 14 章 · 多线程](./14-多线程/)——竞态复现、synchronized、可见性、生产者消费者、死锁

先修:零基础可入门,但本站其他课程(计组的 ISA 与内存、操作系统的线程与锁、数据结构的复杂度)的交叉引用会频繁出现,对照阅读收益翻倍。教材配合:《Java 核心技术》卷 I(查漏)、JavaGuide(面试视角)、阿里《Java 开发手册》(工程规约)。
