# Sherfiter's Wiki

一个 MDX 驱动的静态个人 Wiki(用于个人心得分享和动态更新)

> **⚠️ 复刻声明（Copy from jyy）**
>
> 本项目整体**复刻自 [jyy 的个人 Wiki](https://jyywiki.cn/)**（作者：南京大学 蒋炎岩 / jyy）。



## to get me（node npm做前两步 几秒钟就可以看内容）

```bash

npm install

# 开发模式（热更新）
npm run dev

# 生产构建 + 启动
npm run build
npm start
```

默认地址：http://localhost:3000
